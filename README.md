# Orbit Habit

`Orbit Habit`は、iOS 17以上を対象にした端末内完結型の習慣チェッカーです。SwiftUIとSwiftDataを用い、曜日指定の習慣、完了記録、連続達成、カレンダー、分析、日英切替、ローカル通知を提供します。

## 実装済みの範囲

| 領域 | 実装内容 |
|---|---|
| 今日 | 当日が対象の習慣だけを表示し、ワンタップで完了／取消を記録します。 |
| 習慣 | 最大10件。名称、アイコン、テーマカラー、実行曜日、通知時刻を設定できます。 |
| 振り返り | 連続達成、月間カレンダー、直近7日・30日の達成率、全体の週次達成率を表示します。 |
| 設定 | 日本語・英語の選択、通知の一括制御、手動並び替え、全データ削除を提供します。 |
| 保存 | `Habit`と`CompletionRecord`をSwiftDataへ端末内保存します。 |
| 通知 | 最大6日先までの非繰り返しローカル通知を同期します。完了した当日分は取消します。 |
| 品質 | SwiftLint、Xcodeのビルド時実行、GitHub Actions、ユニットテストを設定しています。 |

## 必要環境

macOS上で**Xcode 16以降**、**XcodeGen**、**SwiftLint**を用意してください。アプリのデプロイメントターゲットはiOS 17.0です。

```bash
brew install xcodegen swiftlint
```

## 起動手順

プロジェクトのルートで次を実行します。

```bash
xcodegen generate
open OrbitHabit.xcodeproj
```

Xcodeで`OrbitHabit`スキームとiOS 17以降のシミュレータを選択して実行してください。初回起動時にはオンボーディングが表示され、最後の画面で通知権限を要求します。

## 品質チェック

SwiftLintの設定は`.swiftlint.yml`にあります。危険な`try!`、強制キャスト、強制アンラップをエラー扱いにし、未使用宣言・未使用importの分析ルールも有効にしています。

| コマンド | 内容 |
|---|---|
| `make generate` | `project.yml`からXcodeプロジェクトを生成します。 |
| `make lint` | SwiftLintを厳格モードで実行します。 |
| `make test` | iOS Simulator上でユニットテストを実行します。 |
| `make verify` | 生成、静的解析、テストを順に実行します。 |

Xcodeプロジェクトにはビルド前のSwiftLintスクリプトも含まれます。さらに`.github/workflows/ios-quality.yml`が、プルリクエストと`main`へのpush時にmacOSランナーでXcodeGen、SwiftLint、ユニットテストを実行します。

## 通知の設計

通知は曜日ごとの繰り返し登録ではなく、日付を固定した1回限りの通知として登録します。この方式により、完了した習慣の**当日分だけ**を取り消せます。アプリが起動・フォアグラウンド復帰・習慣編集・完了操作を行うたびに、今後6日間の通知を再同期します。

端末内完結の初版では、アプリを長期間まったく起動しない場合に無期限の条件付き通知を保証することはできません。将来この保証が必要になった時点で、リモート通知とサーバー側スケジューリングを検討してください。

## プロジェクト構成

```text
OrbitHabit/
├── App/                  # アプリ起点、タブ、オンボーディング、共有依存
├── Models/               # SwiftDataモデル
├── Domain/               # 曜日・ローカル日・指標の純粋ロジック
├── Services/             # 記録操作、設定、通知の副作用
├── Features/             # 画面単位のSwiftUI実装
├── DesignSystem/         # ダークSF調の色・カード・リング
└── Resources/            # 日本語・英語のローカライズ資源
```

## 注意事項

このリポジトリには、再現可能な`project.yml`を含めています。Xcodeプロジェクト自体は環境ごとの差分を避けるため、`xcodegen generate`で生成する運用です。App Store公開前には、`PRODUCT_BUNDLE_IDENTIFIER`を固有の値へ変更し、実機で通知許可・ダーク表示・アクセシビリティ・ローカライズを確認してください。
